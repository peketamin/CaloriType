# CaloriType 操作モック

ビルド不要のHTML/CSS/JavaScript。PC・スマホ幅で操作を確認できます。

## ローカル確認

```sh
python3 -m http.server 8080 --directory dist
```

http://localhost:8080 を開きます。IndexedDBにはlocalhostまたはHTTPSを使ってください。

## 操作できるもの

- 名前の部分一致候補・自由入力、前回値の再利用、グラム/個数/食分、分数・kcal調整とPFC比例変更
- 外食スイッチ、±10ポイント補正、ラベル（このモックの率範囲は−90〜200%、初期0%）
- 追加・編集・削除、セッション内Undo/Redo（デフォルト1000、設定で変更）
- マウス/タッチで食事ブロック間の移動、編集画面で移動先の選択（時刻を保持）
- 日ごとの20時〜翌6時、15分刻みの区切りと所属日の再計算
- 記録完了状態、カレンダー、週合計、天秤、期間別の調整量
- IndexedDB保存、JSONバックアップ/全体復元、Markdown書き出し
- 15食品の編集、食品用JSONの書き出し・同じIDでの上書き/追加
- 食事ブロックの名称変更、チュートリアル、非表示にできる日替わりの言葉

## 未実装・簡略化

これは操作確認用です。初期の食品値と体重はサンプルで、配布用食品マスターの精査は未完了です。

自動の体重目標算出、目標変更の履歴、意味検索モデルによるPFC推測、ブロック追加/アーカイブ、完全な時間比例タイムライン、原本が破損した場合の高度な救出、複数端末同期は未実装です。

PFCの自動補完は内蔵食品と前回値によるものです。未知の食品は不明として入力できます。診断・修復メニューはバックアップの書き出し、基本形式検証、画面集計の再構築までです。

保存と履歴は少量データのモック用実装です。10万件の性能や、採用予定の差分履歴・増分集計の検証は行っていません。統計は現在の目標値で比較し、画面にその制限を表示します。
