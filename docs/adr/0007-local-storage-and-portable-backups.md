# ADR-0007: 端末内保存から始めJSON復元を可能にする

日付：2026-11-03  
状態：採用（会話で合意した方針。未決事項は採用に含めない）  
関連：[デザインドック](../design.md) / [ADR一覧](README.md)

## 背景

最初からオンライン同期は実装しないが、将来的には複数端末で使いたい。今の記録を利用者が取り出し、戻せる必要がある。

## 検討した選択肢

- 最初からアカウントとオンライン同期を必須にする。
- 端末内に閉じ、書き出しだけを用意する。
- 端末内保存から始め、JSON復元と将来の同期を設計上考慮する。

## 決定

同期導入までは端末内に保存する。JSONとMarkdownへ書き出し、JSONから復元できるようにする。

追加・編集・削除を可能にし、元に戻す・やり直すを用意する。削除も取り消せる。初版の完成条件では、入力・再利用・編集・復元を優先して固め、長期統計は段階的に磨く。

## 理由と影響

アカウントなしで記録を始められる。端末内保存だけでは端末紛失やブラウザデータ削除に備えられないため、バックアップと失敗時の表示が必要。

復元用JSONにはスキーマ版と設定・目標履歴を含める設計案とする。読めるMarkdownは復元用の正本にしない。同期時には安定ID、版、所有者、認証・認可、競合・削除、暗号化を別途設計する。

端末内保存と高速化の要件は、localStorageや特定DBの採用を意味しない。大量データの検証とインデックス方式を決める。

## 未決事項

永続化技術、復元の上書き/マージ/重複判定、移行、取り消し範囲と保持期間、保存容量、性能の数値目標、同期とiOSの実装順序。
