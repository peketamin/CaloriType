# ADR-0007: クラウドアカウントを必須にせず端末内保存から始める

日付：2026-11-03  
状態：採用  
関連：[PRD](../design.md) / [技術設計](../technical-design.md)

## 決定と理由

初版からクラウドアカウントとオンライン同期を前提にする方式にはせず、端末内保存とJSON書き出し・復元から開始する。

まず入力・再利用・編集・復元を固める段階であり、同期の認証・競合・運用まで最初の利用条件にすると、その価値検証が遅れるから。

## 引き受ける不利益

複数端末へ自動同期しない。端末紛失やブラウザデータ消去へ備えるにはバックアップが必要で、将来の同期には移行設計が要る。保存の具体技術は技術設計で扱う。

## 見直す条件

本人の利用が複数端末へ広がるなど、端末間の移動が主要な障害になったとき。
