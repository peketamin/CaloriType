# ADR-0002: 材料別レシピを必須にせず1食分と前回値を再利用する

日付：2026-11-03  
状態：採用  
関連：[PRD](../design.md) / [技術設計](../technical-design.md)

## 決定と理由

初版で料理を材料ごとに積み上げるレシピ管理は必須にせず、「カレー1食分」の値を登録し、前回の量・栄養値を補完する。

利用者が求めているのは料理の精密な作り込みより、いつもの食事を少ない手間で記録・調整できることだから。

## 引き受ける不利益

材料や出来上がり重量からの自動再計算はできない。料理や量が変われば本人が値を調整する。

## 見直す条件

試用で、材料や出来上がり量の変化が主な修正負担となり、1食分の再利用だけでは目的を満たせないとわかったとき。
