# ADR-0006: 未完了を摂取ゼロとせず完了日だけで差分を出す

日付：2026-11-03  
状態：採用  
関連：[PRD](../design.md) / [技術設計](../technical-design.md)

## 決定と理由

未記録や一部だけの入力を「その日の全摂取量」として扱う方式にはせず、未記録・途中・完了を区別し、長期調整の差分には完了日を使う。

朝食だけの入力や記録忘れを0や低摂取と扱うと、実在しない予算の余地を示し、日々の調整判断を誤らせるから。

## 引き受ける不利益

利用者には完了操作の負担が増える。完了日数を表示し、完了後の食事変更では途中へ戻して再確認する。

## 見直す条件

試用で完了操作の負担が継続を妨げ、同等に未記録と区別できる別の方法が見つかったとき。
