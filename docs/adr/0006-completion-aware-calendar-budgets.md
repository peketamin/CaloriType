# ADR-0006: 記録完了日と暦の期間で調整予算を計算する

日付：2026-11-03  
状態：採用（会話で合意した方針。未決事項は採用に含めない）  
関連：[デザインドック](../design.md) / [ADR一覧](README.md)

## 背景

未記録を摂取ゼロとすると、余地があるように誤表示される。1日の増減だけではなく、長期的なペースを把握したい。

## 検討した選択肢

- 未記録日を0 kcalとして集計する。
- 入力が1件でもあれば完了とみなす。
- 未記録・入力途中・記録完了を分け、完了日だけで長期差分を計算する。
- 期間に移動する過去N日を使う、または暦の区切りを使う。

## 決定

日ごとに未記録・入力途中・記録完了を区別する。未記録はゼロと扱わず、長期の差分計算には記録完了日を使う。意図的に食べなかった日は明示的に完了できる。

週は月〜日、四半期は1〜3月など、半年は1〜6月・7〜12月、年は1〜12月の暦で集計する。

週は残りの日の1日あたり、月は四半期まで、四半期は半年まで、半年は年末までの1週あたりの調整量を示す。例：300 kcal超過して残り3日なら、目標から100 kcal/日を控える。

カレンダーの記録日の背景は目標付近を薄い緑、過剰を赤系にし、週合計も表示する。

## 理由と影響

未記録を余剰予算と誤認させず、当時の目標を基に差分を分散できる。カレンダーの日次合計と、完了日だけを使う調整差分は区別して表示する。

上位期間の差分を各カードから足し合わせると二重計上する。計算対象日と完了日数を明示し、期限端で0除算しない。式の提案はデザインドックに記載する。

## 未決事項

今日を残りの日に含めるか、完了後の編集、部分週、将来の目標の継承、上位期間での差分の集約範囲。履歴が少ない場合の天秤と助言の表示も決める。

## 2026-11-03 追加合意

以下は初版の未決事項を更新する決定。初版と異なる点は本節を優先する。

完了後の食事変更で入力途中へ戻し、再完了で長期差分へ反映する。長期調整は翌日以降、期限当日は差分のみ。週表示は1日あたり×7と残り日数を併記。上位期間の開始から集計して二重加算しない。将来の適用日ごとに目標を合計する。未設定の将来目標の継承は未決。
