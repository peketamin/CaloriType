# ADR-0008: 初期食品データを編集可能にし外食補正を別管理する

日付：2026-11-03  
状態：採用  
関連：[デザインドック](../design.md) / [決定状況](../open-decisions.md) / [ADR一覧](README.md)

## 背景

一般的な頻出食品は初期登録されていてほしい。一方、自分の料理や商品に合わせて値を直し、ファイル経由でも更新したい。外食には割合で補正を加えたい。

## 決定

- 頻出食品・料理を初期登録する。画面から編集し、食品データのエクスポート・インポートで上書きできる。
- 本人の登録・前回値を優先し、基準量・単位・出典を表示する。
- 全体バックアップの復元と食品データの上書きインポートを区別する。
- 外食はスイッチと±10パーセントポイントのボタンで調整し、外食ラベルをメタデータとして保持する。
- 元の栄養値と補正率を分け、再利用・切り替えで重複適用しない。PFCも比例変更する。

## 設計案

食品には安定IDを付け、配布元データの版と本人の上書きを分ける。初期データ更新で本人の編集を消さず、初期値へ戻す操作を設ける。食品マスターの変更は過去の食事のスナップショットへ遡及させない。

補正率rの適用は、未補正の現在値×(1+r/100)。r=20%から「+10%」はr=30%であり、補正済み値×1.1ではない。画面ラベルでこの意味を明確にする。

## 未決事項

収録データ・出典・利用条件、食品用のファイル形式・照合と衝突、配布版更新と本人編集の優先ルール。補正率の初期値・範囲、外食の記憶の粒度も未指定。

## 影響

初期データ、上書き、記憶、実記録を区別して持つ必要がある。インポートでは検証・事前プレビュー・退避を行う設計とする。
