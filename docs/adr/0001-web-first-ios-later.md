# ADR-0001: Webから開始し将来iOSへ展開する

日付：2026-11-03  
状態：採用（会話で合意した方針。未決事項は採用に含めない）  
関連：[デザインドック](../design.md) / [ADR一覧](README.md)

## 背景

最初に入力と調整の使い心地を検証したい。一方、将来的にはiOS標準アプリと同等の品質を目指し、iOSアプリとして提供したい。

## 検討した選択肢

- 最初からiOSアプリを作る。
- Webで開始し、体験の検証後にiOSへ展開する。

## 決定

最初はWebアプリとして作る。将来のiOS展開を前提にするが、iOSの実装方式・配布方式・コード共有率は現時点では決定しない。Apple HIGを参考にし、チュートリアルを用意する。

## 理由と影響

ブラウザで入力の流れを検証しやすい。WebとiOSで計算やデータの意味が食い違わないよう、画面とは独立した計算仕様とデータ形式を定義する必要がある。これはコード共有の保証ではない。

## 未決事項

Webの技術スタック、対応ブラウザ、PWA・オフライン対応、iOSの技術スタックとコード共有範囲。Goの時計アプリは別の先行作業であり、CaloriTypeの技術選定を意味しない。
