# ADR-0001: 最初からiOS専用にせずWebで体験を検証する

日付：2026-11-03  
状態：採用  
関連：[PRD](../design.md) / [技術設計](../technical-design.md)

## 決定と理由

最初の提供形態としてiOS専用アプリを作る案にはせず、Webアプリから開始する。

手入力・量の調整・再利用の体験を先に試すことを優先しており、ブラウザで確認できる形がその進め方に合うため。

## 引き受ける不利益

iOSの標準操作や配布の体験は後続で作り込む。WebのコードをそのままiOSへ流用できるとは限らない。

## 見直す条件

Webで検証した結果、最初からiOSの機能や操作が必須だとわかったとき。
