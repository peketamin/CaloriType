# ADR-0004: 日ごとの終了境界と変更可能な食事ブロックを使う

日付：2026-11-03  
状態：採用（会話で合意した方針。未決事項は採用に含めない）  
関連：[デザインドック](../design.md) / [ADR一覧](README.md)

## 背景

深夜に食べた食事を生活上の前日へ含めたい。また食事の分類が固定だと、利用者の生活に合わない。

## 検討した選択肢

- 常に暦の0時で分け、固定の食事分類を使う。
- 全期間へ同一の区切り時刻を適用する。
- 日ごとの終了境界と変更可能な分類を使う。

## 決定

原則24時で1日を区切る。バーのドラッグで日ごとの終了を変更でき、他の日の設定に一括反映しない。

縦の時間スケールに色分けした食事ブロックを表示する。デフォルトは朝食・昼食・夕食・夜食で、設定から変更できる。食事アイテムをブロック間でドラッグ＆ドロップできる。

## 理由と影響

11月3日を翌2時までにした場合、11月4日1時の食事を11月3日分として扱える。実際の日時と所属日を分ける必要がある。境界変更や移動で記録を複製したり、隣接する日から脱落させたりしない。

元の画像・コード案にあった「間食」は最終のデフォルトではなく、合意したデフォルトは「夜食」である。

## 未決事項

ドラッグ範囲・刻み、隣接日間の境界制約、所属日変更の取り消し、タイムゾーン・旅行、ブロック設定変更と既存記録の扱い。時間に比例したブロックの高さと、ドラッグ以外で移動する手段も設計する。
