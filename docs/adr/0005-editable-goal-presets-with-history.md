# ADR-0005: 体重目標から提案し編集可能な目標履歴を持つ

日付：2026-11-03  
状態：採用（会話で合意した方針。未決事項は採用に含めない）  
関連：[デザインドック](../design.md) / [ADR一覧](README.md)

## 背景

利用者に最初から目標カロリーの知識を求めず、体重目標を起点にしたい。ただし自動提案をそのまま強制したくない。

## 検討した選択肢

- 目標カロリーを全て手入力する。
- 自動計算だけで確定する。
- 自動計算をプリセットとして提案し、利用者が編集する。

## 決定

現在体重・目標体重・目標日と、身長・年齢・計算に必要な身体条件・活動量などを基に目標カロリーを提案する。提案を編集して確定できる。

初版では活動量を設定し、運動ごとのカロリー自動加算はしない。目標の変更は指定日以降へ適用し、過去は当時の目標で評価する。

天秤は摂取カロリーの超過を表し、オーバーペースで傾きと赤みを変える。実測体重の減り方や将来体重の予測を表さない。

## 理由と影響

自動提案の手軽さと利用者による調整を両立する。計算式の根拠と適用条件を確定する必要があり、プロトタイプの仮の目標を本番の提案式として流用しない。

目標の適用開始日と当時の確定値を保存する。目標の再計算で過去の統計を変更しない。

## 未決事項

基礎代謝等の計算式、必須属性、活動係数、上下限、極端・達成不能な目標の扱い、提案理由の表示、PFC目標と実測体重の入力範囲。計算式が決まり次第、別ADRへ記録する。
