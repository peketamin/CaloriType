# ADR-0005: 現在のマスターへ追従させず過去は当時の値を保つ

日付：2026-11-03  
状態：採用  
関連：[PRD](../design.md) / [技術設計](../technical-design.md)

## 決定と理由

食品マスターや現在の目標を変更するたびに過去の記録・評価を再計算する方式にはせず、食事は当時の栄養値、評価は当時適用された目標を保持する。

前回値や初期食品を本人向けに編集できるため、現在値への追従では過去の摂取量・超過が本人の操作意図と無関係に変わり、記録を信頼できなくなるから。

## 引き受ける不利益

食事のスナップショットと目標の履歴が必要になる。本人が過去の食事自体を編集する操作と、マスターを変える操作を区別する。

## 見直す条件

過去へ意図的に再適用する明示的な機能が必要になったとき。その場合も無操作での遡及は行わない。
