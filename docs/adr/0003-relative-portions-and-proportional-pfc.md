# ADR-0003: 現在値を基準に量を調整しPFCも比例変更する

日付：2026-11-03  
状態：採用（会話で合意した方針。未決事項は採用に含めない）  
関連：[デザインドック](../design.md) / [ADR一覧](README.md)

## 背景

食べた量を分数またはカロリーの増減で素早く調整したい。分数の意味と連続操作の基準が曖昧だと結果を予測しにくい。

## 検討した選択肢

- 基準量の分数を加算・減算する。
- 食べた量を分数にし、毎回元の基準値から計算する。
- 食べた量を分数にし、その時点の値から計算する。

## 決定

分数ボタン1/8、1/5、1/4、1/3、1/2は、現在の量・カロリーへ乗算する。連続操作も現在値を基準にする。

増減ボタンは±10、±20、±50、±100、±200 kcal。カロリー・量の変更にPFCも比例させる。PFCの割合を表示する。

## 理由と影響

例：400 kcal → 1/2 → 200 kcal → 1/2 → 100 kcal。分数を基準値への増減として解釈しない。

内部の計算精度と表示の丸めを分け、連続操作で誤差が蓄積しない設計が必要。比例変更は油だけを足すような組成変更まで自動推定するものではない。

## 未決事項

0 kcalを基準とする比例変更、PFC不明時、負の値となる減算、丸め、個別PFC編集の詳細。PFCを4/9/4換算によるエネルギー比率で表示する案はデザインドックに記載するが、確定した計算式とは区別する。

## 2026-11-03 追加合意

以下は初版の未決事項を更新する決定。初版と異なる点は本節を優先する。

PFCの名前からの自動推測、個別編集、エネルギー比率表示の方針を採用した。表示はkcal整数・PFC小数1桁、内部精度は保持する。不明と0を区別し、0からの加算で根拠なしにPFCを作らない。特定モデルと不明値の推測方式の詳細は未決。[調査案](../offline-pfc.md)を参照。
