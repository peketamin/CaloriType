# ADR-0010: 自律と継続を支える言葉を日替わりで表示する

日付：2026-11-03  
状態：採用  
関連：[デザインドック](../design.md) / [決定状況](../open-decisions.md) / [ADR一覧](README.md)

## 背景

利用者は自分を律するため、偉人の言葉をランダムに見られる機能を希望した。

## 決定

- ホーム下部に小さな「今日の言葉」を表示する。
- 1日1つランダムに選び、その日は固定する。
- 手動で別の言葉へ切り替えられ、設定で非表示にもできる。
- 著者・作品名・出典への導線を表示する。
- 継続・習慣・節制を中心に、出典と利用条件を確認した20〜30件を初期候補とする。
- 入力中にモーダルや通知で割り込まず、摂取超過を責めるイベントへ連動させない。

## 理由と影響

入力の速さを保ちながら、日々の習慣のきっかけにできる。翻訳や要約は原文と区別し、誤帰属・創作を偉人の引用として配布しない。引用集の情報と表示設定は端末で扱える構成にする。

## 未決事項

実際の引用文、原典・翻訳・利用条件の確認、日付変更の基準、初版の必須完成条件に含めるか。現時点で引用集の収録・権利確認が完了したわけではない。
