# CaloriType（カロリタイプ）

カロリー管理。手入力と過去の記録の補完で、食べた量に合わせてすばやく記録するアプリです。

最初はWebアプリとして開発し、将来iOSアプリへ展開します。自炊を中心に外食の記録も支援し、減量・体重維持・筋力トレーニングに使える設計を目指します。

## 現在の状態

要件定義・操作設計の段階です。このリポジトリには設計文書を収録しており、動作するアプリの実装・起動手順はまだありません。会話で作成した画像は画面イメージであり、実装済み機能や検証済みの計算を表すものではありません。
